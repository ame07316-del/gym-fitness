## الطريقة (على ماك/ويندوز)

```bash
npm run dev        # افتح http://localhost:3000
```

1. DevTools ← `⌥⌘I` ← زر الجهاز `⌘⇧M` ← اختار **1440×900** (أو اكتب المقاس يدويًا في وضع Responsive).
2. اضغط `⌘⇧P` ← اكتب `Capture node screenshot` لو عايز تقص على السكشن نفسه (تقدر تختار أي element من الـ DOM وتعمله كده).
3. أو اختصار النظام: ماك `⌘⇧4` ثم `Space` (يصور عنصر كامل بظلاله) — ويندوز: `Win+Shift+S`.
4. اسم الملف زي الجدول بالظبط، وحطه في المجلد ده.

## لو عايز GIF بدل اللقطات (الأقوى في معرض الأعمال)

- ماك: `⌘⇧5` ← Record Selected Portion ← صوّر 20–30 ثانية للتشيك أوت كامل (باقة ← كوبون ← كارت ← 3DS ← نجاح).
- ارفع الـ MP4 على Loom/YouTube كـ unlisted وحط اللينك في الـ README (السطر جاهز تحت).
- GIF أفضل للمعاينة السريعة: `ffmpeg -i checkout.mp4 -vf "fps=12,scale=1280:-1:flags=lanczos" checkout.gif`
  (لو مش عندك ffmpeg: `brew install ffmpeg` أو استخدم [ezgif.com](https://ezgif.com/video-to-gif)).
