# 🔐 مراجعة الأمان — إيه اللي كان غلط وإيه اللي اتعمل

مراجعة على الريبو كله (سبتمبر ٢٠٢٦) مع إضافة قاعدة البيانات ولوحة الإدارة،
وجولة تانية بعد **إلغاء الدفع بالكروت خالص** و**نقل حساب الأسعار للسيرفر**.
كل بند هنا مربوط بالملف اللي اتعدّل، ومعظمهم مغطّى باختبار.

## 1) ثغرات كانت موجودة واتقفلت

## 2) اللي اتبنى صح من الأول في طبقة الإدارة

**كلمات السر**
- `scrypt` (N=16384, r=8, p=1) بملح 16 بايت لكل مستخدم — مفيش MD5/SHA عارية ومفيش كلمة سر مخزّنة نصًا.
- المقارنة بـ `timingSafeEqual`.
- لما الإيميل مش موجود بنقارن مع **هاش وهمي** عشان زمن الرد يفضل ثابت (منع user enumeration)، والرسالة واحدة في كل الحالات.
- سياسة: 10 حروف + رقم + رفض الكلمات المتوقّعة.

**الجلسات**
- توكن عشوائي 32 بايت، و**اللي بيتخزن هو sha256 بتاعه** — تسريب الداتابيز ما بيديش دخول.
- كوكي `HttpOnly` + `SameSite=Strict` + `Secure` (على https) + `Path=/`.
- انتهاء بالخمول ساعة + سقف مطلق 12 ساعة + تنضيف تلقائي للجلسات الميتة.
- الجلسة بتتحقق من الداتابيز في كل طلب: الحساب اتعطّل أو اتمسح أو اتغيّر دوره → الجلسة تموت في الحال.

**CSRF**
- Double submit مربوط بالجلسة: كوكي `fz_csrf` + هيدر `x-csrf-token`، والسيرفر بيقارن **الهاش** المخزّن في صف الجلسة (`timingSafeEqual`).
- فحص `Origin` مقابل `Host` لكل طلب بيغيّر حالة.
- الاتنين مغطيين باختبارات (`tests/admin-api.test.ts`).

**تخمين كلمات السر**
- قفل الحساب 15 دقيقة بعد 5 محاولات فاشلة + حاجز على الإيميل + حاجز على الـ IP، وكل محاولة فاشلة بتتسجل في `audit_log`.

**التفويض (Authorization)**
- مصفوفة صلاحيات واحدة (`app/lib/auth/roles.ts`) والسيرفر بيتشيك عليها في كل route.
- نطاق الكوتش بيتطبق في **الاستعلام نفسه** (`WHERE coach_id = ?`) مش في الواجهة.
- الحقول المالية بترجع `null` للأدوار اللي مالهاش `revenue:read` — يعني مش بس مخفية في الـ UI.
- الحذف النهائي محصور في المدير العام، وبيتطلب كتابة رقم الطلب في الواجهة كتأكيد.

**سجل العمليات**
- كل دخول/خروج/إلغاء/حذف/تعديل مستخدم بيتسجل بـ: مين، إيه، على مين، الـ IP، والوقت.

**الفلوس**
- مصدر واحد للسعر: `quoteOf()` — الواجهة بتستخدمه للعرض بس، والسيرفر بيعيد حسابه قبل أي تسجيل.
- `POST /api/quote` تسعيرة رسمية (public لكن عليها rate limit 60/10د) — الواجهة تقدر تتأكد من رقمها قبل التأكيد.
- الاشتراك بيتسجّل **`pending`** ومابيتحسبش في الإيراد، والإدارة بتأكد الاستلام من اللوحة (`subscriptions:update`) فيبقى `active` مع `paid_at`/`paid_by` وسطر في سجل العمليات.
- **مفيش أي بيانات بنكية** بتتقبل أو تتخزن: طرق الدفع محفظة/إنستا باي أو كاش في الفرع، واللي بيتخزن أقصاه رقم المحفظة اللي كتبه العضو للمطابقة.

**SQL**
- كل الاستعلامات **prepared statements** بمعاملات مسماة — مفيش string concatenation لأي قيمة جاية من المستخدم.

## 3) حاجات لازمة قبل الإنتاج الحقيقي

1. `DEMO_SEED=0` + `SEED_OWNER_PASSWORD` قوي (أو خد الكلمة المولّدة من اللوج وغيّرها فورًا).
2. HTTPS إجباري (الكوكيز بتبقى `Secure` تلقائيًا، وHSTS بيتحط لوحده).
3. SQLite كويسة لسيرفر واحد. لأكتر من نسخة (Vercel/Kubernetes) انقل لـ Postgres وانقل `rate_limits` لـ Redis.
4. لو حبيت ترجع الدفع الأونلاين يومًا ما: **بوابة بـ tokenization/redirect بس** (رقم الكارت ما يلمسش السيرفر بتاعك) + webhook موقّع يأكد الدفع، ولا ترجّع خانات الكارت للواجهة.
5. 2FA للمدير العام + تنبيه بالإيميل عند تسجيل دخول من جهاز جديد.
6. باك أب دوري لملف الداتابيز (ومتحطهوش في Git — متستثنى في `.gitignore`).
7. مطابقة تحويلات المحافظ آليًا (رقم المحفظة + المبلغ) بدل المراجعة اليدوية لو الحجم كبر.

## 4) إزاي تتأكد بنفسك

```bash
npm test                       # 61 اختبار، منهم صلاحيات وCSRF وقفل الحساب والتلاعب بالأسعار

# البيانات محمية؟
curl -si localhost:3000/api/subscribe | head -1          # 401

# CSRF شغال؟
curl -s -c c.txt -X POST localhost:3000/api/admin/auth/login \
  -H 'content-type: application/json' \
  -d '{"email":"owner@fitzone.pro","password":"Owner#Fit2026"}' > /dev/null
curl -s -b c.txt -X PATCH localhost:3000/api/admin/subscriptions/FZ-2026-DEMO01 \
  -H 'content-type: application/json' -d '{"action":"cancel"}'   # 403 code: csrf

# التلاعب بالسعر؟ (لازم يرجع الإجمالي الحقيقي مش 1 جنيه)
curl -s -X POST localhost:3000/api/subscribe -H 'content-type: application/json' \
  -d '{"planId":"vip","cycle":"yearly","addonIds":[],"payment":"cash","total":1,"months":99,
       "member":{"name":"اختبار التلاعب","phone":"01012345678"}}' | grep -o '"total":[0-9]*'

# الدفع بالكروت اتشال؟
curl -s -o /dev/null -w '%{http_code}\n' -X POST localhost:3000/api/pay   # 404

# الترويسات؟
curl -sI localhost:3000/ | grep -i 'content-security-policy\|x-content-type'
```
